# مشروع متابعة الإيرادات عبر واتساب (Whapi)

توثيق لحالة المشروع بعد جلسة التخطيط الأولى، ليكون نقطة انطلاق للمتابعة لاحقًا.
لا يوجد كود مُنفَّذ بعد — هذا ملخص للقرارات والبيانات التي جُمعت فقط.

## الهدف

استقبال رسائل واتساب من مندوبين محددين ضمن مجموعات محددة عبر Whapi،
واستخراج المبلغ المالي من نص كل رسالة تلقائيًا، وتسجيله كسجل إيراد.

## القرارات المتخذة

- **الفلترة**: فقط رسائل واردة من أرقام/جهات محددة مسبقًا (وليس كل رسالة في القروب).
- **استخراج المبلغ**: تحليل نص الرسالة لاستخراج الرقم (المبلغ) وحفظه كحقل رقمي منفصل، وليس حفظ النص الخام فقط.
- **التخزين**: ملف داخل هذا المستودع (JSON أو CSV) — بدون خدمات خارجية.
- **التشغيل**: يوجد لدى المستخدم خادم/استضافة جاهزة لتشغيل خادم يستقبل webhook من Whapi.
- **لغة التنفيذ**: Node.js (لتتوافق مع إعداد `whapi-mcp` الموجود في `.mcp.json` بجذر المستودع).

## الخطوات التالية المقترحة

1. حسم النقطة المفتوحة أعلاه (تأكيد المجموعة الصحيحة، والانضمام الفعلي إن لزم).
2. تسجيل webhook في إعدادات قناة Whapi يشير إلى خادم المستخدم.
3. بناء خادم Node.js (Express) يستقبل أحداث الرسائل، يفلترها حسب `group_id` + رقم المُرسل (رفيف)، يستخرج المبلغ بتعبير نمطي (regex)، ويحفظه في ملف JSON/CSV ضمن هذا المجلد.
4. إضافة عرض/تقرير بسيط لمجموع الإيرادات المسجّلة (اختياري لاحقًا).
