# مشروع متابعة الإيرادات عبر واتساب (Whapi)

توثيق لحالة المشروع، وخطوات تشغيله ونشره.

## الكود جاهز الآن ✅

تم بناء واختبار خادم استقبال (`server.js`) محليًا بنجاح:
- يستقبل رسائل واتساب الجديدة عبر webhook من Whapi.
- يفلترها حسب رقم المجموعة (`ALLOWED_GROUP_ID`) ورقم المُرسل (`ALLOWED_SENDERS`).
- يستخرج المبلغ رقميًا من نص الرسالة، ويحفظه في `revenues.json`.
- محمي برمز سري بسيط (`WEBHOOK_SECRET`) عبر `?token=...` في الرابط، حتى لا يقدر أي شخص يرسل بيانات وهمية للسيرفر.

## كيف تنشره على Render.com (مجاني، بدون خبرة سابقة)

1. اذهب إلى https://render.com وسجّل حساب مجاني (بإيميلك).
2. اربط حساب Render بحساب GitHub بتاعك (اللي فيه هذا المستودع MAZEN).
3. من لوحة Render: **New +** ← **Web Service** ← اختر مستودع `MAZEN`.
4. في إعدادات الخدمة:
   - **Root Directory**: `revenue-tracking`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. في قسم **Environment Variables** أضف:
   - `WEBHOOK_SECRET` = أي كلمة سرية تختارها بنفسك
   - `ALLOWED_GROUP_ID` = `120363424110851927@g.us` (مجموعة "مارس 2026" — تحقق منها أولاً، راجع "نقطة مفتوحة" أدناه)
   - `ALLOWED_SENDERS` = `9647803521490` (رقم رفيف)
6. اضغط **Create Web Service** وانتظر حتى ينتهي النشر — سيعطيك Render رابطًا مثل: `https://your-app.onrender.com`
7. رابط الـ webhook الكامل الذي سنسجله في Whapi يصير:
   `https://your-app.onrender.com/webhook?token=الكلمة-السرية-اللي-اخترتها`

بعد ما يصير عندك هذا الرابط، أرسله لي وأنا أسجّله فعليًا في إعدادات قناة Whapi.

## تنبيه مهم عن التخزين ⚠️

التخزين حاليًا ملف بسيط (`revenues.json`) على قرص السيرفر. على استضافات مجانية مثل Render Free،
**قد يُمسح هذا الملف عند إعادة تشغيل الخدمة** (بعد فترة خمول أو عند كل نشر جديد). هذا مناسب للتجربة
والبداية، لكن للاستخدام الجاد على المدى الطويل يُفضّل لاحقًا الترقية لخطة فيها قرص دائم (Persistent Disk)
أو استخدام قاعدة بيانات بسيطة. أخبرني إذا وصلنا لهذه المرحلة وسأساعدك بالتبديل.

## الهدف

استقبال رسائل واتساب من مندوبين محددين ضمن مجموعات محددة عبر Whapi،
واستخراج المبلغ المالي من نص كل رسالة تلقائيًا، وتسجيله كسجل إيراد.

## القرارات المتخذة

- **الفلترة**: فقط رسائل واردة من أرقام/جهات محددة مسبقًا (وليس كل رسالة في القروب).
- **استخراج المبلغ**: تحليل نص الرسالة لاستخراج الرقم (المبلغ) وحفظه كحقل رقمي منفصل، وليس حفظ النص الخام فقط.
- **التخزين**: ملف داخل هذا المستودع (JSON أو CSV) — بدون خدمات خارجية.
- **التشغيل**: يوجد لدى المستخدم خادم/استضافة جاهزة لتشغيل خادم يستقبل webhook من Whapi.
- **لغة التنفيذ**: Node.js (لتتوافق مع إعداد `whapi-mcp` الموجود في `.mcp.json` بجذر المستودع).

## الخطوات التالية المقترحة

1. حسم النقطة المفتوحة أعلاه (تأكيد المجموعة الصحيحة، والانضمام الفعلي إن لزم).
2. تسجيل webhook في إعدادات قناة Whapi يشير إلى خادم المستخدم.
3. بناء خادم Node.js (Express) يستقبل أحداث الرسائل، يفلترها حسب `group_id` + رقم المُرسل (رفيف)، يستخرج المبلغ بتعبير نمطي (regex)، ويحفظه في ملف JSON/CSV ضمن هذا المجلد.
4. إضافة عرض/تقرير بسيط لمجموع الإيرادات المسجّلة (اختياري لاحقًا).
